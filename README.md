# Smart Air Quality Analytics Platform with ESP32, MQ-135 & Blynk Cloud

## Overview

An ESP32-based IoT system for real-time air quality monitoring using the MQ-135 gas sensor and Blynk Cloud.

The system acquires air-quality-related sensor data through the ESP32 and transmits the data to a Blynk dashboard for real-time monitoring and visualization.

## Objectives

- Monitor air quality using the MQ-135 sensor
- Interface the MQ-135 sensor with ESP32
- Acquire sensor data in real time
- Transmit sensor readings to Blynk Cloud
- Visualize air-quality data through a cloud dashboard

## System Architecture

MQ-135 Sensor → ESP32 → Wi-Fi → Blynk Cloud → Real-Time Dashboard
